## ✅ 1. Что переносим ЦЕЛИКОМ (логика не меняется)

Эти модули не зависят от платформы (VK или МАКС).
Логика остаётся той же — меняется только транспорт.

### 1.1. Логика слотов

**Файл-источник:** `core/storage/schedule.py`

**Что делает:**
- `get_free_slots()` — свободные слоты на дату
- `get_free_dates()` — свободные даты на N дней
- `get_busy_slots()` — занятые слоты с учётом буфера
- `book_slot()` — бронирование
- `cancel_booking()` — отмена
- `confirm_booking()` — подтверждение
- `add_custom_slot()` — открытие нерабочего слота
- `get_custom_slots()` — список кастомных слотов

**Как переносить:**
- Скопировать логику
- Заменить `SQLITE_PATH` на PostgreSQL-подключение
- Добавить `tenant_id` в каждый запрос
- **Логика не меняется** — только источник данных

### 1.2. Расчёт дат (без AI)

**Файл-источник:** `core/handlers/booking.py` → `parse_date_preference()`

**Что делает:**
- «завтра» → конкретная дата
- «через неделю» → конкретная дата
- «в субботу» → ближайшая суббота
- «15.10» → 15.10.2026

**Как переносить:**
- Скопировать функцию **как есть**
- Она не зависит от платформы или БД
- Работает с чистыми строками

### 1.3. Определение языка (без AI)

**Файл-источник:** `core/i18n/detector.py`

**Что делает:**
- `detect_language(text)` → 'ru' / 'he' / 'en'
- Иврит — по алфавиту
- Кириллица — точно русский
- Латиница — транслит или английский

**Как переносить:**
- Скопировать **как есть**
- Для MAX-продукта (только Россия) — можно упростить до ru
- Но если планируете мультиязычность — оставить

### 1.4. Транслит (латиница → кириллица)

**Файл-источник:** `core/handlers/message_handler.py` → `LAYOUT_MAP`

**Что делает:**
- `ghbdat` → `привет`
- `pfgbcfnmcz` → `записаться`

**Как переносить:**
- Скопировать `LAYOUT_MAP` и функцию `translit_to_ru()`
- Работает **как есть**

### 1.5. Нечёткий поиск команд (difflib)

**Файл-источник:** `core/handlers/message_handler.py` → `fuzzy_match()`

**Что делает:**
- «привте» → «привет»
- «зописаца» → «записаться»
- «прайз» → «прайс»

**Как переносить:**
- Скопировать функцию **как есть**
- Работает с `difflib` из стандартной библиотеки

### 1.6. AI-провайдер (GigaChat)

**Файл-источник:** `core/ai/provider.py`

**Что делает:**
- `get_ai_response()` — ответ от GigaChat
- Кэш токена (25 минут)
- История диалога (последние 10 сообщений)
- System prompt

**Как переносить:**
- Скопировать логику
- GigaChat остаётся провайдером для России
- Добавить `tenant_id` в историю диалогов
- Промпт адаптировать под бизнес-тип

### 1.7. Уведомления мастеру

**Файл-источник:** `core/handlers/booking.py` → отправка `admin_msg`

**Что делает:**
- После записи — уведомление мастеру
- Формат: имя, телефон, услуга, дата, время

**Как переносить:**
- Логика та же
- Меняется только транспорт (MAX API вместо VK)

## 🔄 2. Что переносим С АДАПТАЦИЕЙ (меняется реализация)

### 2.1. Абстракция адаптера

**Файл-источник:** `core/messaging/base.py`

**Что делает:**
- `MessageAdapter` — интерфейс
- `IncomingMessage` — универсальное сообщение
- `Button` — универсальная кнопка
- `MessageHandler` — тип обработчика

**Как адаптировать:**
- **Оставить как есть** — интерфейсы универсальны
- Написать `max_adapter.py`, реализующий `MessageAdapter`
- Ничего в ядре не менять

### 2.2. VK-адаптер → MAX-адаптер

**Файл-источник:** `adapters/vk_adapter.py`

**Что делает:**
- LongPoll → получение событий
- `send_message()` → отправка
- Кнопки VK → клавиатура

**Как адаптировать:**
- **LongPoll → Webhook** (принципиально разное)
- `vk.messages.send()` → `POST /messages` в MAX API
- VK-клавиатура → MAX-кнопки
- **Логика ядра не меняется**

### 2.3. Flask → FastAPI

**Файл-источник:** `web_demo.py`

**Что делает:**
- Flask-сервер
- Маршруты для кабинета
- Авторизация

**Как адаптировать:**
- Flask → FastAPI (для Webhook МАКСа)
- Маршруты кабинета — переписать под FastAPI
- Авторизация — логика та же, синтаксис другой

### 2.4. SQLite → PostgreSQL

**Файлы-источники:** все `core/storage/*.py`

**Что делает:**
- Работа с SQLite
- Прямые SQL-запросы

**Как адаптировать:**
- SQLite → PostgreSQL (SQLAlchemy)
- Добавить `tenant_id` во все запросы
- Добавить миграции (Alembic)
