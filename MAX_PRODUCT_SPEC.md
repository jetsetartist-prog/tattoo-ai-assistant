# 📘 MAX PRODUCT SPEC — AI-администратор для мастеров (Россия, МАКС)

**Дата создания:** 18.09.2026
**Статус:** Draft v1.0
**Платформа:** МАКС (мессенджер)
**Рынок:** Россия

---

## 🎯 1. Цель продукта

**AI-администратор для мастеров-одиночек в сфере услуг.**

Мастер не настраивает бота — он даёт боту данные (услуги, цены, FAQ),
а бот сам консультирует, записывает клиентов и ведёт CRM.

**Формула:** «Мастер нажимает одну кнопку — и вся его онлайн-работа автоматизирована.»

---

## 🔄 2. Отличие от VK-бота (что переносим, что пишем заново)

**Переносим (логика):**
- Архитектура `core/` + `adapters/`
- Логика слотов и бронирования
- CRM: клиенты, услуги, история
- AI-ассистент (промпты, контекст)
- Мультиязычность (пока только ru)
- Календарь, статистика, настройки

**Пишем заново (транспорт):**
- Webhook вместо LongPoll
- FastAPI вместо Flask
- `max_adapter.py` вместо `vk_adapter.py`
- PostgreSQL вместо SQLite
- Мультитенантность с самого начала

## 👥 3. Целевая аудитория

**Мастера-одиночки в России:**
- Парикмахеры
- Косметологи
- Мастера татуажа
- Мастера лазерной депиляции
- Мастера ногтевого сервиса

## 🏗 4. Архитектура

```
┌─────────────────────────────────────────────┐
│              ЯДРО (core/)                    │
│  AI, CRM, слоты, booking, FAQ, настройки    │
│  Не знает про МАКС — работает с абстракциями │
└─────────────────────────────────────────────┘
                    ↑
                    │
┌─────────────────────────────────────────────┐
│         ADAPTER (adapters/max/)              │
│  Webhook, отправка, кнопки, вложения         │
└─────────────────────────────────────────────┘
                    ↑
                    │
┌─────────────────────────────────────────────┐
│              МАКС API                        │
│  Webhook, send_message, attachments          │
└─────────────────────────────────────────────┘
```

**Ключевой принцип:** ядро **не знает**, что работает с МАКСом.
Оно работает с `MessageAdapter`, `IncomingMessage`, `Button`.
Позже можно добавить Telegram, WhatsApp, Instagram — без переписывания ядра.

## 🧰 5. Технический стек

- **Python 3.11+**
- **FastAPI** — для Webhook-сервера МАКСа
- **Uvicorn** — ASGI-сервер
- **PostgreSQL** — основная БД (мультитенантность)
- **Redis** — кэш, сессии, очереди (опционально)
- **SQLAlchemy** — ORM
- **Alembic** — миграции БД
- **GigaChat** — AI-провайдер (для России)
- **Yandex SMTP** — email
- **Docker** — упаковка
- **Nginx** — reverse proxy + HTTPS
- **VPS** — хостинг (когда будет бюджет)

## 🗄 6. Структура БД

### Таблица `tenants` (мастера/аккаунты)
- `id`, `email`, `password_hash`
- `business_type` — тип бизнеса (только для шаблонов услуг)
- `language` — ru/he/en
- `currency` — RUB/ILS/USD
- `max_token`, `max_bot_id` — интеграция с МАКС
- `webhook_url` — для МАКСа
- `plan`, `plan_until` — подписка
- `is_active` — включён ли бот

### Таблица `masters`
- `id`, `tenant_id`, `name`, `phone`, `email`
- `work_hours` — график работы (JSON)

### Таблица `services`
- `id`, `tenant_id`, `name`
- `duration_minutes` — длительность
- `buffer_minutes` — перерыв (по умолчанию 0)
- `price_from`, `price_to` — диапазон цен
- `is_active`

### Таблица `faq`
- `id`, `tenant_id`, `question`, `answer`
- `order` — порядок отображения

### Таблица `settings`
- `id`, `tenant_id`, `key`, `value`
- Ключи: `cancellation_policy`, `address`, `map_url`, `deposit_info`

### Таблица `clients`
- `id`, `tenant_id`, `name`, `phone`, `email`, `notes`

### Таблица `bookings`
- `id`, `tenant_id`, `master_id`, `client_id`, `service_id`
- `date`, `time`, `duration`, `status`
- `source` — `online` / `manual`
- `notes`, `reference_image`
- `price`, `deposit`

### Таблица `custom_slots`
- `id`, `tenant_id`, `master_id`, `date`, `time`

## 🧩 7. Модули продукта

### ✅ Делаем в MVP
1. **Бот в МАКСе** — приветствие, меню, запись, AI-консультации
2. **CRM** — клиенты, услуги, история визитов
3. **Календарь** — рабочая неделя, слоты, custom slots
4. **Настройки бота** — услуги, FAQ, правила (без конструкторов)
5. **Статистика** — визиты, выручка, загрузка
6. **Мультитенантность** — один сервер, много мастеров
7. **Авторизация** — email + пароль, Yandex SMTP

### ⏳ Откладываем
- Пакеты услуг (мастера не любят)
- Групповые услуги (пока)
- Онлайн-оплата (СБП вручную)
- SMM-планер (следующий этап)
- TargetHunter (только для VK, не для МАКСа)
- Реклама в МАКСе (пока не автоматизируется)

### ❌ НЕ делаем
- Конструктор ботов (мастер не должен настраивать)
- Инструкции для AI (мастер не пишет промпты)
- Парсинг аудиторий (нелегально)

## 📱 8. Интеграция с МАКС

**Платформа для партнёров:** `platform-api2.max.ru`

**Архитектура:** Webhook (не LongPoll)
- МАКС присылает события на ваш URL
- Вы отвечаете через `POST /messages`

**Требования:**
- HTTPS обязателен
- Публичный домен
- Модерация бота

**Для мастера:**
1. Регистрация на Платформе для партнёров МАКС
2. Создание бота
3. Прохождение модерации
4. Получение токена
5. Ввод токена в кабинете → бот работает

**Лимиты:**
- Самозанятые — до 2 ботов
- ИП/юрлица — до 5 ботов

---

## ⚙️ 9. Настройки бота (без конструкторов)

Мастер заходит в кабинет (с телефона) и видит **три блока**:

### Блок 1: «Услуги» (таблица)
| Название | Длительность | Цена от | Цена до |
|---|---|---|---|
| Восковая депиляция | 30 мин | 1500 | 2500 |
| Татуаж бровей | 2 ч | 8000 | 12000 |

### Блок 2: «Частые вопросы» (список)
| Вопрос | Ответ |
|---|---|
| Как подготовиться? | Не пить кофе за 2 часа... |
| Это больно? | Используем анестезию... |

### Блок 3: «Правила» (текст)
- Депозит: 1000₽
- Отмена: за 24 часа
- Адрес: ...
- Карта: ссылка

**Мастер НЕ пишет:** «как бот должен отвечать», «инструкции для AI».
Он только **даёт данные** — бот сам решает, как их использовать.

## 🔀 10. Универсальность (business_type)

**`business_type` нужен только для:**
- Подстановки шаблонов услуг при регистрации
- Промпта AI («Ты ассистент косметолога»)
- Названий в интерфейсе (опционально)

**Логика записи, слотов, CRM — универсальна.**
Мастер сам прописывает услуги: сегодня «восковая депиляция»,
завтра «татуаж бровей» — без изменения кода.

## ☁️ 14. Инфраструктура

**Для разработки:** локально (ПК) + CloudPub для демо.

**Для production:**
- VPS (Hetzner, Timeweb, Selectel) — от 500₽/мес
- Домен — от 1000₽/год
- HTTPS — Let's Encrypt (бесплатно)
- Docker + Nginx + Supervisor
- PostgreSQL (managed или на VPS)

**Важно:** МАКС требует **публичный HTTPS** для Webhook.
Без VPS бот не заработает в production.
