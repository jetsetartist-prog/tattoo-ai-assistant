## ✅ Что работает

### Мультиплатформенная архитектура
- `core/` — ядро, не зависит от платформы
- `adapters/` — платформенные обёртки
- VK-адаптер: longpoll + автопереподключение (логика из старого бота)
- Web-адаптер: Flask + веб-чат

### Ядро (`core/handlers/message_handler.py`)
- Приветствие, меню
- Нечёткий поиск команд (опечатки) — `difflib`
- Транслит (латиница → кириллица) — `LAYOUT_MAP`
- Команды: прайс, портфолио, контакты, записаться
- Fallback на AI, если не распознано

### AI (`core/ai/provider.py`)
- GigaChat (кэш токена, история диалогов)
- System prompt с описанием салона

### Форма записи (`core/handlers/booking.py`)
- 5 шагов: имя → телефон → стиль → размер → дата
- Парсинг дат без AI: «завтра», «через неделю», «в субботу», «15.10» → конкретная дата
- Сохранение лида в SQLite + CSV
- Уведомление админу

### Расписание (`core/storage/schedule.py`)
- Таблицы: masters, work_hours, days_off, services, bookings
- `get_free_slots()` — свободное время на дату
- `get_free_dates()` — свободные даты на N дней
- `book_slot()` — бронирование
- `cancel_booking()` — отмена
- Дефолт: Пн–Пт 10–20, Сб 12–18, Вс выходной

### Авторизация (`core/auth/`)
- Вход: email + постоянный пароль
- Пароль: генерируется читаемый (`Tattoo-A7k9-Mn2p`)
- Отправка через Yandex SMTP
- Хеширование через `werkzeug.security`
- Сессии в памяти (7 дней)
- Восстановление пароля
- Смена пароля в кабинете

### Кабинет (`templates/`)
- `/admin/login` — вход
- `/admin/forgot-password` — восстановление
- `/admin` — главная
- `/admin/schedule` — настройка графика
- `/admin/settings` — смена пароля

### Веб-чат (`web_demo.py`)
- Стиль WhatsApp
- Кнопки, автоскролл, индикатор «печатает»

## 🔑 Ключевые решения

1. **core + adapters** — чтобы работало на любой платформе без переписывания ядра.
2. **Парсинг дат без AI** — дешевле, быстрее, надёжнее.
3. **Постоянный пароль** вместо одноразовых кодов — удобнее для мастера, браузер запоминает.
4. **Читаемый пароль** (`Tattoo-A7k9-Mn2p`) — легко диктовать по телефону.
5. **SQLite** — пока хватает для MVP, но для SaaS перейдём на PostgreSQL.
6. **Кабинет как в Booksy** — «смены» и гибкость, а не жёсткая сетка YCLIENTS.
