## ✅ Что работает

### Мультиплатформенная архитектура
- `core/` — ядро, не зависит от платформы
- `adapters/` — платформенные обёртки
- VK-адаптер: longpoll + автопереподключение
- Web-адаптер: Flask + веб-чат

### Ядро (`core/handlers/message_handler.py`)
- Приветствие, меню
- Нечёткий поиск команд (опечатки) — `difflib`
- Транслит (латиница → кириллица) — `LAYOUT_MAP`
- **Определение языка автоматически** (ru/he/en) — `core/i18n/detector.py`
- Команды: прайс, портфолио, контакты, записаться — **на 3 языках**
- Fallback на AI (только для ru/en)

### AI (`core/ai/provider.py`)
- GigaChat (кэш токена, история диалогов)
- System prompt с описанием салона
- **Для иврита AI не используется** — только заготовки

### Форма записи (`core/handlers/booking.py`)
- 5 шагов: имя → телефон → размер → дата → время
- Парсинг дат без AI («завтра», «через неделю»)
- Сохранение лида в SQLite + CSV
- Уведомление админу
- **Мультиязычность** (ru/he/en)

### Расписание (`core/storage/schedule.py`)
- Таблицы: masters, work_hours, days_off, services, bookings
- `get_free_slots()` — свободное время на дату
- `get_free_dates()` — свободные даты на N дней
- `book_slot()` — бронирование
- `cancel_booking()` — отмена
- `confirm_booking()` — подтверждение
- Пароли мастеров (хеш, восстановление, смена)

### Авторизация (`core/auth/`)
- Вход: email + постоянный пароль
- Пароль: генерируется читаемый (`Tattoo-A7k9-Mn2p`)
- Отправка через Yandex SMTP
- Хеширование через `werkzeug.security`
- Сессии в памяти (7 дней)
- Восстановление пароля
- Смена пароля

### Кабинет (`templates/`)
- `/admin/login` — вход
- `/admin/forgot-password` — восстановление
- `/admin` — главная
- `/admin/schedule` — настройка графика
- `/admin/bookings` — список записей (с фильтрами)
- `/admin/calendar` — календарь на неделю
- `/admin/settings` — смена пароля
- **Мультиязычность** (ru/he/en) с кнопками в правом верхнем углу
- **RTL для иврита**

### Мультиязычность (`core/i18n/`)
- **Определение языка** без AI (алфавит + биграммы)
- **Транслит** — понимает `ghbdat` как `привет`
- **97 ключей** на язык
- **Переключатель** в кабинете: `[RU][EN][HE]`
- **RTL** для иврита (dir="rtl")
- AI — только ru/en, иврит — заготовки

### Веб-чат (`web_demo.py`)
- Стиль WhatsApp
- Кнопки, автоскролл, индикатор «печатает»

### Git + GitHub
- Репозиторий: https://github.com/jetsetartist-prog/tattoo-ai-assistant
- 1 коммит (48 файлов, 6176 строк)
- `.env` защищён через `.gitignore`
- Резервная копия в облаке

## 🔑 Ключевые решения

1. **core + adapters** — чтобы работало на любой платформе без переписывания ядра.
2. **Парсинг дат без AI** — дешевле, быстрее, надёжнее.
3. **Определение языка без AI** — по алфавиту и биграммам.
4. **Постоянный пароль** — удобнее для мастера, браузер запоминает.
5. **Читаемый пароль** (`Tattoo-A7k9-Mn2p`) — легко диктовать.
6. **SQLite** — для MVP; для SaaS — PostgreSQL.
7. **AI только ru/en** — GigaChat не знает иврит; для иврита — заготовки.
8. **RTL для иврита** — `dir="rtl"` в `<html>`.
9. **Git + GitHub** — резервная копия + история.
